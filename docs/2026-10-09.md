## feat: android 모듈 - SMS·통화 기록·패키지·APK 권한 분석

- 워크스페이스에 `android` 크레이트 추가 (서브커맨드 sms / calls / packages / apk, 표 기본 + `--json`)
- sms: mmssms.db, ms → 초 변환, type 1~6(received/sent/draft/outbox/failed/queued) 매핑, NULL 값 보존
- calls: contacts2.db / calllog.db, type 1~6(incoming/outgoing/missed/voicemail/rejected/blocked) 매핑
- SQLite는 `immutable=1` + READ_ONLY로 열어 증거 무결성 유지, 테이블/컬럼 누락 시 SchemaMismatch
- packages: 텍스트 XML(quick-xml)과 Android 12+ ABX 바이너리 XML 지원, 실제 AOSP 속성 `it`/`ut`(16진수 ms) 기준
- apk: AXML 파싱(UTF-8/UTF-16 문자열 풀, rawValue/typed value, 리소스 ID 기반 android:name), 위험 권한 26종 필터링
- 손상 입력 방어: 모든 오프셋 범위 검증, 압축 해제 16MiB·입력 256MiB 상한, 건너뛴 항목 수 stderr 경고
- 설계 문서 대비 변경: 출력 기본값을 기존 모듈과 동일하게 표로, packages 시각 속성명 실제 형식으로 정정
- 테스트 48개 추가 (단위 12, 통합 36), clippy 경고 0개

## refactor: SQLite 읽기 전용 헬퍼를 common으로 이동

- `common::sqlite` 추가: `open_immutable`(immutable=1 + READ_ONLY), `require_columns`, 값 변환 헬퍼
- android 크레이트가 common 헬퍼를 사용하도록 변경

## feat: ios 모듈 - SMS·통화 기록·KnowledgeC·Quarantine

- 워크스페이스에 `ios` 크레이트 추가 (서브커맨드 sms / calls / knowledgec / quarantine, 표 기본 + `--json`)
- sms: message LEFT JOIN handle(핸들 없는 메시지 보존), CoreData epoch 초/나노초(iOS 11+) 자동 판별, text가 NULL이면 attributedBody에서 본문 추출
- calls: CallHistory.storedata ZCALLRECORD, ZORIGINATED → 발신 여부
- `common::apple` 추가: KnowledgeC / Quarantine 파서를 macOS·iOS 공통 구현으로 통합
- knowledgec: ZDEVICEID 유무·ZSOURCE 조인을 스키마에 따라 동적 처리해 macOS형·iOS형 모두 지원, NULL 행 보존
- 테스트 30개 추가 (ios 16, common 14), clippy 경고 0개

## fix: macos KnowledgeC·Quarantine을 공통 구현으로 이전

- immutable=1로 열어 WAL DB에서 -shm 생성 위험 제거
- NULL 값이 있는 행이 조용히 사라지던 문제 수정 (bundle_id/ZENDDATE NULL 보존, Quarantine 시각 NULL 보존)
- ZDEVICEID 컬럼이 없는 버전에서 쿼리 실패하던 문제 수정
- 출력 시각 형식 변경: `YYYY-MM-DD HH:MM:SS` → RFC3339 UTC (`...+00:00`)
- 공개 API(`read_app_usage`, `read_quarantine`, 타입 이름)는 유지
