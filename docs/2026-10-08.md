## fix: disk 파티션 판별 및 BPB 검증

- MBR 시그니처 비교값 수정 (0x55AA → 0xAA55, LE 읽기 기준) — 정상 이미지에서 partitions가 항상 실패하던 문제
- GPT 판별을 부팅 플래그(sector[446]) 대신 첫 파티션 타입 바이트(sector[450] == 0xEE)로 변경
- BPB 검증 추가 (bps, sectors_per_cluster, num_fats, root_cluster) — 0 나누기/언더플로 패닉 대신 `DiskError::InvalidBpb` 반환
- PartitionSlice 음수 seek 시 끝 위치로 이동하던 문제를 InvalidInput 에러로 변경
- 테스트 11개 → 24개, clippy 경고 0개
